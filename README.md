# Sidecar Portrait

사이드카(Sidecar)로 연결한 아이패드를 **세로 방향**으로 쓰게 해 주는 macOS 메뉴 막대 앱입니다.

macOS의 사이드카는 화면 회전을 지원하지 않아서, 아이패드를 세워도 화면은 가로 그대로 나옵니다. 이 앱은 세로 방향 가상 디스플레이를 만들고 그 화면을 90도 돌려 아이패드에 보여 줍니다.

## 기능

- 사이드카가 연결되면 자동으로 세로 모드를 켜고, 끊기면 자동으로 끕니다.
- 메뉴 막대 아이콘을 누르면 설정 패널이 뜹니다.
  - 세로 모드 켜기/끄기와 현재 상태 표시
  - 해상도: 기본 / 넓게 / 더 넓게 (아이패드 크기에 맞춰 자동 계산)
  - 아이패드를 돌려 세운 방향: 시계 방향 / 반시계 방향
  - 세로 화면 위치: 자동 / 왼쪽 / 오른쪽 / 위 / 아래
  - 커서 가두기, 로그인할 때 자동으로 실행
- 메뉴 막대 아이콘이 상태에 따라 바뀝니다. 동작 중이면 꽉 찬 모양, 꺼져 있거나 대기 중이면 윤곽선입니다.

## 요구 사항

- Apple Silicon 맥, macOS 14 이상
- Xcode 또는 Xcode Command Line Tools (`swiftc`)
- 사이드카를 지원하는 아이패드

## 빌드와 설치

```bash
./build.sh
```

```bash
cp -R build/SidecarPortrait.app /Applications/
```

```bash
open /Applications/SidecarPortrait.app
```

처음 실행하면 **화면 기록 권한**을 요청합니다. 시스템 설정 → 개인정보 보호 및 보안 → 화면 및 시스템 오디오 녹음에서 허용한 뒤 앱을 다시 실행하세요.

`./build.sh`는 기본으로 임시(ad-hoc) 서명을 합니다. 이 경우 다시 빌드할 때마다 화면 기록 권한을 새로 허용해야 합니다. 코드 서명 인증서가 있으면 그 ID를 인자로 주면 권한이 유지됩니다.

```bash
./build.sh "Apple Development: ..."
```

## 사용법

1. 평소처럼 사이드카로 아이패드를 연결합니다.
2. 앱이 "iPad Portrait"라는 세로 모니터를 만들어 원래 사이드카가 있던 자리에 놓습니다.
3. 아이패드를 90도 돌려 세웁니다. 화면이 거꾸로 보이면 설정 패널에서 방향을 바꿉니다.
4. 창을 "iPad Portrait" 모니터로 옮기면 아이패드에 세로로 보입니다.

앱을 종료하면 가상 디스플레이가 사라지고 화면 배치가 원래대로 돌아갑니다.

## 제한 사항

- **애플 펜슬·터치 입력은 지원하지 않습니다.** 화면만 회전하므로 아이패드에서 터치한 좌표가 회전된 화면과 맞지 않습니다. 마우스와 키보드로 사용하세요.
- 원래 사이드카 화면은 앱의 전체 화면 창에 가려집니다. 거기 있던 창을 꺼내려면 세로 모드를 잠시 끄세요.
- 화면을 캡처해 다시 그리는 구조라 약간의 지연이 있고, 화면 기록 표시가 뜹니다.
- "넓게"와 "더 넓게" 해상도는 큰 화면을 아이패드 픽셀에 맞춰 축소하므로 "기본"보다 조금 덜 선명합니다.
- 가상 디스플레이 생성에 macOS **비공개 API**(`CGVirtualDisplay`)를 사용합니다. macOS 업데이트 후 동작하지 않을 수 있고, Mac App Store에는 올릴 수 없습니다.

## 동작 원리

1. 사이드카 화면의 가로·세로를 뒤바꾼 크기로 `CGVirtualDisplay` 가상 디스플레이를 만듭니다.
2. ScreenCaptureKit으로 그 가상 디스플레이를 아이패드 패널의 픽셀 크기로 캡처합니다.
3. 캡처한 프레임을 90도 회전한 레이어에 올려, 사이드카 화면을 덮는 전체 화면 창에 그립니다.

가상 디스플레이의 레티나(HiDPI) 모드는 맨 처음 등록한 모드에 대해서만 쓸 수 있고, 모드가 하나뿐이면 아예 만들어지지 않습니다. 그래서 해상도를 바꿀 때마다 원하는 모드를 첫 번째로 해서 둘 이상을 다시 등록합니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `Sources/main.swift` | 앱 본체: 가상 디스플레이, 화면 캡처, 출력 창 |
| `Sources/SettingsView.swift` | 설정 값과 설정 패널(SwiftUI) |
| `Sources/StatusIcon.swift` | 메뉴 막대 아이콘 그리기 |
| `Sources/CGVirtualDisplayPrivate.h` | 비공개 API 선언 |
| `build.sh` | 빌드 스크립트 |

## 문제 해결

로그는 `~/Library/Logs/SidecarPortrait.log`에 남습니다.

실행 중인 앱에 신호를 보내면 진단 이미지를 `~/Library/Logs/SidecarPortrait-*.png`로 저장합니다. 아이패드에 나가는 화면, 가상 디스플레이, 설정 패널이 포함됩니다.

```bash
kill -USR1 $(pgrep -f "SidecarPortrait.app/Contents/MacOS")
```
